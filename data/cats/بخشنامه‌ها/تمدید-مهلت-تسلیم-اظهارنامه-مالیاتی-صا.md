# تمدید مهلت تسلیم اظهارنامه مالیاتی صاحبان مشاغل و فرم تبصره ماده صد سال ۱۴۰۴ تا پایان آبان

> منبع: https://www.ekhtebar.ir/%d8%aa%d9%85%d8%af%db%8c%d8%af-%d9%85%d9%87%d9%84%d8%aa-%d8%aa%d8%b3%d9%84%db%8c%d9%85-%d8%a7%d8%b8%d9%87%d8%a7%d8%b1%d9%86%d8%a7%d9%85%d9%87-%d9%85%d8%a7%d9%84%db%8c%d8%a7%d8%aa%db%8c-%d8%b5%d8%a7/

پایگاه خبری اختبار- رئیس کل سازمان امور مالیاتی کشور با ابلاغ بخشنامه‌ای از تمدید مهلت ارائه اظهارنامه مالیات بر درآمد صاحبان مشاغل، فرم مالیات مقطوع تبصره ماده (۱۰۰) قانون مالیات‌های مستقیم و پرداخت مالیات عملکرد سال ۱۴۰۴ تا پایان آبان‌ماه سال جاری خبر داد.

به گزارش اختبار، سید محمدهادی سبحانیان با ابلاغ بخشنامه‌ای به ادارات کل امور مالیاتی اعلام کرد:

در راستای تسهیل امور مودیان، به موجب مصوبه مراجع قانونی، مهلت تسلیم اظهارنامه مالیات بر درآمد صاحبان مشاغل، فرم مالیات مقطوع تبصره ماده (۱۰۰) قانون مالیات‌های مستقیم و پرداخت مالیات متعلق بابت عملکرد سال ۱۴۰۴ تا تاریخ ۱۴۰۵/۸/۳۰ تمدید می‌شود.
